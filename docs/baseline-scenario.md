# Continuity Keeper Baseline Experiment

## Purpose

Test the unmodified Continuity Keeper prompt against a use case involving
one persistent fictional character existing across multiple independent
realities.

The purpose is to observe actual behavior before making any changes to
the prompt.

## Prompt Under Test

Unmodified upstream Continuity Keeper:

prompts/continuity-keeper-original.md

No Scoped Canon modifications may be used during this experiment.

## Character

Pickles:

- Purple dragon
- Breathes ice
- Loves pizza
- Afraid of chickens

## Intended Reality A — Space World

Establish:

- Pickles lives on Mars.
- Pickles meets a green alien named Zorp.
- Zorp becomes Pickles' friend.

## Intended Reality B — Pirate World

Start a separate reality and establish:

- Pickles is captain of a pirate ship.
- Pickles has never been to Mars.
- Pickles does not know Zorp.
- In this reality, Pickles breathes fire.

## Observations to Capture

Do not assume any particular failure.

Observe whether Continuity Keeper:

1. Recognizes the two intended realities as separate.
2. Recalls Space World information while operating in Pirate World.
3. Treats "Pickles has never been to Mars" as conflicting with Space World.
4. Treats fire breath as conflicting with the established ice-breath trait.
5. Attempts to supersede or retcon existing canon.
6. Provides another behavior not anticipated by this test.
7. Successfully handles any part of the scenario.

## Evidence

Capture:

- Complete interaction transcript
- MemWal namespaces used
- Blob IDs created
- Relevant recall results
- Screenshots
- Screen recording
- Notes describing observed behavior

## Rule

Do not modify Continuity Keeper during the baseline experiment.

Any proposed Scoped Canon changes must be written only after reviewing
the baseline results.
